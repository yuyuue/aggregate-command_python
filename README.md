# aggregate-command_python

Pythonの勉強用。
経費CSVを検証・集計してレポートを出力するCLIツール。
目的: 業務でPythonを扱えるようになる / Python 3 エンジニア認定実践試験の取得。

## お題

経費精算のCSV（日付・部署・申請者・カテゴリ・金額など）を読み込んで、次のことをする。

- 不備のある行を検出する（金額が負、日付が不正、必須項目が空、上限超過など）
- 部署別・月別・カテゴリ別に集計する
- 結果をコンソール / JSON / CSV のいずれかで出力する

※ サンプルデータは自作のダミーのみ。実業務のデータは入れない。
